# 沪上邻里 · 上海生活便利度 MVP

基于真实 OpenStreetMap 上海设施快照，结合网格中心到已收录设施点的球面直线距离和周边独立设施数量评分。地图使用 MapLibre GL JS / OpenFreeMap；距离、空间检索和调参都在浏览器本地完成，无需高德账号或距离 API Key。

## 本地运行

需要 Node.js 20 或更高版本，不需要安装 npm 依赖：

```sh
cd land-rating
npm run dev
```

打开终端输出的 `http://127.0.0.1:4173/`。可用 `PORT=其他端口 npm run dev` 修改端口。

```sh
npm test
npm run build
```

`dist/` 为可部署的纯静态网站。Web Worker 需要通过 HTTP/HTTPS 打开，不能直接双击 HTML。在线底图需要网络；评分数据和 MapLibre 代码已随应用打包，不使用公共 OSM 瓦片服务器批量下载。

## GitHub Pages

项目支持部署到 GitHub Pages 的仓库子路径。仓库 `Settings → Pages → Build and deployment → Source` 选择 **GitHub Actions**。推送到 `main` 后，[发布工作流](.github/workflows/pages.yml) 会运行评分测试、构建并发布 `dist/`，也可在 Actions 页面手动运行。

GitHub 仓库：<https://github.com/huyumars/land-rating>。Pages 启用并首次部署成功后，网站地址为 <https://huyumars.github.io/land-rating/>。

工作流使用仓库自带的 `GITHUB_TOKEN`，无需配置个人令牌或其他 Secrets。仅部署网站和开放数据；缓存 PBF、虚拟环境、环境变量与 Git 元数据不会进入站点。

## 已实现

- 默认分析郊环（G1503 上海绕城高速）内；可切换中心城区局部、徐汇、静安、浦东、主要陆域和当前地图视野。
- 默认 500 米网格，支持 100 / 250 / 500 / 1000 米固定网格；按上海边界中心过滤，并排除已绘制水面中的中心点。默认区域还要求中心在郊环内，边缘网格按郊环多边形裁切。
- 地铁、学校、商场、咖啡店、运动设施、图书馆六类的最近距离、周边数量、分项评分与综合评分。
- 默认距离占 70%、数量占 30%；数量占比可调，统计半径支持 500 / 1000 / 2000 米，达到各类数量目标后封顶。
- 六类权重滑杆、三种预设、可调距离阈值和数量目标；权重自动归一，参数可本机保存。
- 高对比五色分档；默认按当前区域分位数对比，支持固定 0–100 分模式；动态图例显示分数范围和网格数量，同分同色。
- 网格点击详情、设施直线连接、本地设施名称搜索、设施点图层。
- CSV 结果、原始 POI GeoJSON、评分参数 JSON 导出；本地 GeoJSON 导入。
- 地图加载失败提示、区域规模限制、计算 Worker、窄屏参数面板。

总计 9,687 个设施点、8,386 个设施组，上海行政边界 relation/913067，5,464 个已绘制水面多边形。数量按每类的 `groupId` 去重，距离保留入口和子设施点。详情见 [data/README.md](data/README.md) 和 `data/metadata.json`。数据使用 ODbL-1.0，保留 © OpenStreetMap contributors 标注。MapLibre 许可证在 `vendor/MAPLIBRE-LICENSE.txt`。

原始 PBF 与隔离 Python 环境在 `.cache/`（不提交、不部署）。使用 `scripts/extract_osm.py` 可从本地 PBF 重新提取；Python 依赖见 `scripts/requirements-data.txt`，不属于运行网页的依赖。

`data/suburban-ring.geojson` 保存郊环内分析边界及来源说明，依据现状通行道路围合范围，包含北侧共线路段；西侧越出上海数据包的道路由同日江苏快照补齐，均截至 2026-10-20T20:23:47Z。它不使用矩形或凸包代替道路边界，也不作为行政区界或法定范围认定。地图以深绿色轮廓标出该范围，默认载入和重置时均选择郊环内。

边缘几何交集使用 MIT 许可的 polygon-clipping 0.15.7，离线代码及上游许可保存在 `vendor/`，无需运行时安装依赖。

## 计算与复用

网格使用以 `[121.47, 31.23]` 为固定原点、参考纬度 31.23° 的局部米制投影。POI 最近邻使用三维单位球 KD 树，报告地表球面距离，避免以地图像素或 Web Mercator 差值代替实际米数。

距离分：距离不超过 good 为 100，达到 max 为 0，区间内线性递减。数量分：`100 × min(半径内独立设施数 / targetCount, 1)`。每类得分为 `(1 - 数量占比) × 距离分 + 数量占比 × 数量分`，默认数量占比 30%，统计半径 1000 米。同样最近距离下，更多附近设施会提高分数，达到目标后封顶；数量占比 0% 可恢复仅按最近距离评分。

综合分为正权重类别归一加权。某类有数据但半径内没有设施，数量为 0；整类没有任何数据或所需数量尚未计算则为未知。缺失正权重类别时总分为 null，另保存 partialScore 和覆盖比例。CSV 包含最近距离、独立设施数量、距离分、数量分、分项分、统计半径和数量占比。

调整权重、距离阈值、数量目标和数量占比只重评分；改变统计半径、网格或区域时在本机重新检索，均不发出距离服务请求。重新访问会载入打包快照；需要最新设施时，替换快照并重新构建发布。新增两类由已缓存的同一份 PBF 提取，无需再下载原始数据。

## 重要边界

- OSM 是社区维护的数据，覆盖可能不均、设施可能过时；这些数量不是上海设施普查。分数和“最近”仅针对已收录记录。
- 多边形商场、学校使用内部代表点，通常不是入口；地铁保留每个单独出入口用于距离，数量按站点归组。地铁归属包含有距离上限的邻近推断，运动场馆合并依赖已绘制边界，仍可能重复或误关联。
- 运动设施与图书馆排除明确标注 `access=no/private` 的对象；未标访问限制、会员或顾客限制、校园开放情况不保证公众可进入。
- 学校没有区分学段，不代表质量、学区或入学资格。
- 直线距离不计算道路、跨江绕行、围墙、封闭园区及开放时间。
- 以网格中心做边界与水面过滤；默认郊环区域的边缘格进一步按郊环多边形裁切，固定采样中心保持不变。其他观察区域沿用中心筛选；水面、行政区边界未逐格精确裁切，未绘制的水面可能保留。
- “上海主要陆域”分析框为 `[120.85, 30.65, 122.05, 31.89]`，不含行政边界的全部远海水域。
- 设施导入仅在本机内存中使用，刷新恢复打包数据；输入为 WGS84 Point FeatureCollection，category 必须为 cafe/mall/school/metro/sports/library，可用相同 `groupId` 合并同站入口或同一场馆的子设施。

## 免注册版本

此版本仅使用免费 OSM 数据与 OpenFreeMap 底图，不需要注册高德、不需要 API Key，也不包含付费接口。设施数据可在本地反复计算；在线底图仍需要网络。
